BOX2Div

Esta es una extension o interfaz para la utilizacion de Box2D.

Box2D es una libreria para simulacion de fisica para juegos, originalmente creado para su uso en C++, pero se puede encontrar para otros lenguajes, en este caso javascript para navegadores que soporten html5.

Box2Div, es como se mensiono una interfaz para el uso web mas facil de la libreria, en este caso se añadio la opcion de trabajar con el touch de los dispositivos mobiles que originalmente no posee.

Iniciando Box2Div:

Lo primero que se necesita son las librerias jQuery, jquery.ui.touch, Box2D y Box2Dvis debidamente incorporadas al html.

<script type="text/javascript" src="js/jquery.js"></script>
<script type="text/javascript" src="js/jquery.ui.touch.js"></script>
<script type="text/javascript" src="js/Box2D.js"></script>
<script type="text/javascript" src="js/Box2Div.js"></script>

Ahora necesitamos crear una instancia de Box2Div:

var box2dInstance = new Box2Div ();

Aunque la interfaz tiene valores por defecto, estos valores pueden ser sobreescritos.

set_density: densidad del objeto en relacion a su tamaño, simulando su masa.
set_friction: repulsion entre objetos al colisionar.
set_restitution: valor de reposicion del objeto despues de colisionar con otro.
set_gravity_X: gravedad en el eje "X".
set_gravity_Y: gravedad en el eje "Y".
set_mouse: por defecto, los objetos no son seleccionables, para hacerlo asi, es necesario invocar esta funcion.

box2dInstance.set_density (50);
box2dInstance.set_friction (20);
box2dInstance.set_restitution (0.8);
box2dInstance.set_gravity_X (0);
box2dInstance.set_gravity_Y (0);
box2dInstance.set_mouse ();

Es necesario aplicar almenos una (preferiblemente la base) de las cuatro aristas en las cuales los objetos tienen como limite, imaginemos una caja, cada uno de los lados seran los limites que los objetos no atravesaran.
En el ejemplo se setean todos los limites menos el de arriba, el cual se setea con comillas dobles.

Recuerde: Los parametros deben ser selectores jQuery, y deben ser siempre ID unicos, no clases.
El orden de los parametros son TOP, RIGHT, BOTTOM, LEFT.

box2dInstance.set_ground ("","#right","#bottom","#left");

Es necesario pasar por parametro todos los objetos a los que se les quiere aplicar la experiencia, recuerde que debe ser un string tipo selector.

box2dInstance.set_content("#links, div#searchform .divider, h4");

Se pueden setear objetos con atributos unicos dentro de su html tag, los atributos son "density", "friction", "restitution", "static" (true/false, significa que el objeto puede quedar estatico dentro de la experiencia o no).

<div id="element" density="100" friction="2" restitution="2" static="true">
    CONTENT
</div>

Existe un callback que se puede setear si es necesario: "onStart":

box2dInstance.on_start (function(){
    alert("hello world!");
});

Es importante tener todo seteado antes de iniciar, sobre todo se se usan animaciones javascript de cualquier tipo, de lo contrario, los "setInterval" pueden lerdear la experiencia sobre todo en los navegadores basados en "webkit".

Para inicial la experiencia:

box2dInstance.start ();
